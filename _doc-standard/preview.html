Cadre & pilotage › Contexte & objectifs

Contexte & objectifs

MAJ : 2026-07-28

Le projet

Site vitrine + acquisition pour Amusoire : réservation de salles privées côté grand public, et démarchage d'établissements (bars, hôtels, campings…) pour la solution de licences.

Objectifs

  • Générer des leads B2C (réservations, événementiel) et B2B (licences établissements).
  • Router chaque lead vers le bon CRM selon sa nature.
  • Rendre le client autonome sur le contenu (blog, pages) sans casser le site.

Cibles

B2CParticuliers, EVG/EVJF, anniversaires, entreprises (team building)Occasions, Lieux, Réserver
B2BBars, restaurants, hôtels, campings, loisirs indoorPages /pro/*, simulateur

Périmètre

Dans : site Webflow, formulaires, tracking, simulateur, popup, blog. Hors : campagnes payantes, production de contenu éditorial.

🟪 Piège — ne pas « corriger »

Contre-intuitif mais exact : les formulaires pro vont sur AMUSOIRE, l'événementiel + newsletter sur BLINDTEST. Routage réel via le champ caché data-portal — ne pas « rétablir la logique ».

Le levier de routage

// script global — l'attribut data-portal du <form> décide le portail
account_target = form.getAttribute('data-portal') || 'amusoire';
// blindtest → 147562037 · amusoire → 25692189

Incident & correctif (pattern)

Symptôme
Un form /team-building remontait sur le mauvais portail.
Cause racine
La modale pro / contact modal impose data-portal="amusoire" en dur, partagé par ses instances.
Correctif
Détacher (unlink) l'instance sur la page, puis data-portal="blindtest".
Étendre
Toute page pro hérite d'amusoire — ne détacher que pour l'événementiel.
🔴 Danger

La clé secrète du webhook Make n'est jamais dans la doc ni dans git → 1Password. Voir Secrets & posture.

Features sur-mesure › Simulateur ROI

Simulateur ROI

MAJ : 2026-07-28Page : /pro/simulateur

Ce que c'est

Un calculateur de gains pour les établissements. Formulaire multi-étapes, résultats chiffrés, puis email récap (via Resend).

Logique de calcul

Les coefficients sont éditables sans code via des Custom Attributes Webflow. Le calcul se fait dans calculator.ts (bundle JS).

Bundle JS — mise à jour

  1. Modifier le code dans src/.
  2. npm run build → dist/index.js + dist/index.css.
  3. Coller dans Webflow → /simulateur → Custom Code (head + before </body>).
  4. Publier sur staging d'abord.
🟪 Piège

La doc technique détaillée du simulateur vit dans la Docsify live de la cliente — ne pas la dupliquer ici, la lier ↗.

Features sur-mesure › Popup opt-in

Popup opt-in

MAJ : 2026-07-28Page : /modal

Architecture

Modale Finsweet + un script déclencheur (affichage à l'intention de sortie / au scroll). Le contenu est une page Webflow dédiée (/modal).

Éditer le contenu

Dans le Designer, ouvrir la page /modal et modifier textes/visuels comme n'importe quelle page — sans toucher au script.

🟨 Avertissement

Ne pas modifier les modalités d'affichage (fréquence, déclencheur) sans prévenir : c'est piloté par le script global.

Éditer le site — Webflow

Module plateforme : WebflowMAJ : 2026-07-28

Les principes sont agnostiques (page précédente) ; les gestes ci-dessous sont Webflow. Sur Shopify ou Astro+Sanity, seule cette page change.

🚫 Les interdits
  • Pas d'emoji / caractères spéciaux dans les slugs.
  • Ne pas toucher aux champs techniques / ID (Make, Memberstack).

Publier un article — 3 étapes

  1. Save as Draft — sauvegarde sans publier.
  2. Stage for Publish — prêt pour la prochaine mise en ligne.

« Publish » pousse tout le site en prod. En cas de doute, reste sur Stage for Publish et préviens Coolbeans.

SEO, Tracking & RGPD › Tracking / provenance

Tracking & provenance des leads

MAJ : 2026-07-28

L'URL = source de vérité

Les paramètres utm_* présents dans l'URL sont pré-remplis en champs cachés et remontés dans HubSpot → on sait d'où vient chaque lead.

Cookie hutk (attention)

🟪 Piège

Le script de tracking HubSpot chargé est celui du portail 25692189 → le hubspotutk lui appartient. Les forms du flux BLINDTEST (147562037) reçoivent donc un hutk cross-portail ignoré. À aligner si on veut l'attribution parcours côté BLINDTEST.

Glossaire
