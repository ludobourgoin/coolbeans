Page `/pro/simulateur` · Portail **AMUSOIRE `25692189`** · Source : `PASSATION.md` (repo `ludobourgoin/amusoire`).

Le prospect simule le CA additionnel généré par les jeux Amusoire dans son établissement. À la soumission : création du contact HubSpot + mail récap personnalisé via Resend.

## Flow & stack

```text
Étape 1 — Secteur d'activité (radios)
Étape 2 — Modes d'utilisation (1 à 3 checkboxes) : RDV récurrents · Espace privatif · Team Building
Étape 3 — Saisie des données (blocs conditionnels selon l'étape 2)
Étape 4 — ROI calculé (CA brut, coût licence, gain net)
Étape 5 — Contact + submit → Webhook Make → HubSpot + Resend
```

| Couche | Outil | Rôle |
| --- | --- | --- |
| Design / DOM | Webflow | Structure HTML, classes, styles |
| Multi-step form | Inputflow | Navigation entre étapes, transitions |
| Logique custom | Bundle TS (repo `amusoire`) | Validation, affichage conditionnel, calcul ROI, hidden fields |
| Bundler | esbuild | Build → `dist/index.js` + `dist/index.css` |
| Orchestration | Make | Réception du form, dispatch HubSpot + Resend |
| CRM | HubSpot `25692189` | Contact / company / form submission |
| Email | Resend (`send.amusoire.com`) | Mail récapitulatif |

<Callout type="note" title="Note — pourquoi Resend">
  Le mail prospect passe par Resend, pas par HubSpot : l'add-on Transactional Email HubSpot coûte ~600 $/mois. Resend : délivrabilité équivalente, quota gratuit 3 000 mails/mois (100/jour), découplé du CRM.
</Callout>

## Calculs & coefficients

Deux niveaux de modification :

- **Coefficients business** : sans code, via Custom Attributes Webflow (ci-dessous).
- **Formules** : dans `src/utils/calculator.ts`, puis `pnpm build` et re-collage du bundle (voir Bundle JS).

Attributs posés sur `.simulator_form-wrapper` (Designer → Settings → Custom Attributes) :

| Attribut | Défaut | Description |
| --- | --- | --- |
| `data-rdv-rate` | `0.3` | Taux de majoration F&B pour les RDV (30 %) |
| `data-privatif-ratio` | `1.5` | m² nécessaires par joueur (privatif) |
| `data-rdv-monthly-licence` | `159` | Coût mensuel licence RDV (€) |
| `data-privatif-monthly-licence` | `279` | Coût mensuel licence Privatif (€) |

| Bloc | Formule CA annuel | Palier licence mensuel |
| --- | --- | --- |
| RDV | `#rdv-ca × rdv-rate × 52` | 159 € |
| Privatif | `(#input-surface ÷ privatif-ratio) × #input-prix-joueur × #input-jours × 52` | 279 € (BUSINESS) |
| Team Building | `#input-personnes × #input-prix-joueur-team-b × #input-frequence × 12` | gratuit (0) |

<Callout type="piege" title="Piège — palier max, pas la somme">
  **Coût licence annuel = `max(paliers cochés) × 12`**. Plusieurs objectifs cochés = une seule licence, la plus élevée. Ex : RDV + Privatif → `max(159, 279) × 12 = 3 348 €`, et non `(159 + 279) × 12`.
</Callout>

**Gain net annuel** = CA total − coût licence. <span class="todo">À faire (reporté)</span> : mention « tarif valable pour un engagement 24 mois » (confirmée le 2026-07-24), non implémentée.

**Recalcul** : au chargement, à chaque input/checkbox, au clic « Étape suivante » (délai 100 ms pour Inputflow), et quand le step ROI devient visible (`MutationObserver`) : les hidden inputs sont à jour au submit.

## Pipeline Make + Resend

```text
Webhook (id 3) → Router 12
  ├─ Route 1 : Flux Amusoire   (account_target = "amusoire") → HubSpot CRM
  ├─ Route 2 : Flux Blindtest  (account_target = "blindtest")
  └─ Route 3 : Mail simulateur (account_target = "amusoire" AND form_type = "simulateur")
      ├─ SetVariables "chunks" (id 51)              — 7 chunks HTML en variables
      ├─ SetVariables "blocs conditionnels" (id 52) — 7 if(truthiness) + cta_url
      └─ Resend "Send an Email" (id 47)             — squelette avec {{52.bloc_*}} et {{52.cta_url}}
```

<Callout type="danger" title="Danger — filtre de la route 3">
  Colonne A = la **variable Make** (`{{3.payload.data.account_target}}`), colonne B = la **string littérale**. L'inverse (texte brut en colonne A) rend le filtre toujours faux → aucun mail. Le double filtre est indispensable : sans `form_type = simulateur`, un mail partirait pour **toutes** les soumissions Amusoire.
</Callout>

## CTA dynamique du mail

Le bouton CTA pointe vers l'un de 4 calendriers HubSpot Meetings selon le couple **(département, secteur)** : variable `cta_url` calculée dans le module 52 depuis `zip` et `secteur-activite`.

| Critère | Calendrier |
| --- | --- |
| Département 75, tout secteur | `…/thisisblindtest/rdv-demo` |
| Hors 75 — Bar/Restaurant ou Hôtel | `…/noemie-boiton/rdvdemo` |
| Hors 75 — Camping/Club ou Loisirs | `…/maxime-costeau/reserver-demo` |
| Hors 75 — Autre (fallback) | `…/noemie-boiton/rdv-demo` |

```text
{{if(substring(3.payload.data.zip + ""; 0; 2) = "75";
  "https://pro.thisisblindtest.com/meetings/thisisblindtest/rdv-demo";
  if(get(3.payload.data; "secteur-activite") = "bar-restau" | get(3.payload.data; "secteur-activite") = "hotel";
    "https://pro.thisisblindtest.com/meetings/noemie-boiton/rdvdemo";
    if(get(3.payload.data; "secteur-activite") = "camping" | get(3.payload.data; "secteur-activite") = "loisirs";
      "https://pro.thisisblindtest.com/meetings/maxime-costeau/reserver-demo";
      "https://pro.thisisblindtest.com/meetings/noemie-boiton/rdv-demo")))}}
```

- **Slugs ≠ labels** : Webflow envoie le slug (`bar-restau`, `hotel`, `camping`, `loisirs`, `autre`), pas le label affiché.
- `zip + ""` caste le zip (number) en texte avant `substring` ; `get(…)` est obligatoire car `secteur-activite` contient un tiret (la dot-notation serait lue comme une soustraction).
- Tester les 4 buckets : History → « Run once » en modifiant le payload (`75010` · `33000 + bar-restau` · `44000 + camping` · `69000 + autre`).

## Vigilance

- `required` sur blocs masqués : géré par `conditionalDisplay.ts` (`dataset.wasRequired`) — ne pas retirer cette logique.
- Checkbox RGPD : validation JS (`validation.ts`), ne pas réactiver `required` côté Webflow.
- Coefficients business : toujours passer par les Custom Attributes, pas par le code.
- Scénario Make : stable — le mail prospect = 3 modules (51/52/47) sur la route 3, pas de scénario séparé. Ne pas réécrire les branches existantes.
- Flags : strings `"true"`/`""`, jamais `"false"`.
- CTA : 4 URLs en dur dans la formule du module 52 — à mettre à jour si un calendrier change ou un commercial arrive.
- API Key Resend : jamais dans le repo (module Make / coffre client).
- En prod : vérifier que le script est bien inliné, aucune référence `cdn.jsdelivr.net/gh/ludobourgoin/amusoire` (404, repo privé).

```ts
/**
 * calculator.ts
 * Calcule en temps réel l'impact sur le CA, affiche les résultats dans l'écran 4,
 * et remplit les hidden inputs du formulaire pour le payload Make → Resend (mail prospect).
 *
 * Formules CA :
 *  - RDV       : CA (#rdv-ca) × rdv-rate × 52
 *  - Privatif  : (Surface (#input-surface) ÷ privatif-ratio) × Prix (#input-prix-joueur) × Jours (#input-jours) × 52
 *  - Team B.   : Personnes (#input-personnes) × Prix (#input-prix-joueur-team-b) × Fréquence (#input-frequence) × 12
 *
 * Coût de licence : palier le plus élevé parmi les objectifs cochés × 12 (PAS la somme).
 *  - RDV = 159 €/mois · Privatif (BUSINESS) = 279 €/mois · Événementiel = gratuit (0).
 *  - Ex : RDV + Privatif → max(159, 279) × 12 = 3 348 € (une seule licence BUSINESS).
 *
 * Config (Custom Attributes sur .simulator_form-wrapper) :
 *  - data-rdv-rate              : taux de majoration F&B pour les RDV (défaut : 0.3 → 30%)
 *  - data-privatif-ratio        : m² nécessaires par joueur (défaut : 1.5)
 *  - data-rdv-monthly-licence   : coût mensuel licence RDV (défaut : 159 €)
 *  - data-privatif-monthly-licence : coût mensuel licence Privatif (défaut : 279 €)
 *
 * Hidden inputs remplis (cf. PASSATION.md §3) :
 *  - hidden-ca-rdv, hidden-ca-privatif, hidden-ca-team-building, hidden-ca-total
 *  - hidden-cout-licence, hidden-gain-net
 *  - hidden-flag-rdv, hidden-flag-privatif, hidden-flag-team-building, hidden-flag-tout-coche
 */

/** Formate un nombre en chaîne lisible avec séparateur d'espace (ex: 12 500) */
const formatNumber = (value: number): string => {
  return Math.round(value).toLocaleString('fr-FR');
};

/** Lit la valeur numérique d'un input par son ID. Retourne 0 si l'élément est absent ou vide. */
const getInputValue = (id: string): number => {
  const el = document.getElementById(id) as HTMLInputElement | null;
  if (!el) return 0;
  const parsed = parseFloat(el.value);
  return isNaN(parsed) ? 0 : parsed;
};

/** Injecte du texte dans un élément par son ID, sans écraser l'unité (€) adjacente. */
const setResultText = (id: string, value: number): void => {
  const el = document.getElementById(id);
  if (el) el.textContent = formatNumber(value);
};

/** Écrit une valeur dans un input caché (par ID). Utilisé pour le payload Make/Resend. */
const setHiddenValue = (id: string, value: string): void => {
  const el = document.getElementById(id) as HTMLInputElement | null;
  if (el) el.value = value;
};

/** Retourne true si la checkbox correspondante est cochée */
const isChecked = (name: string): boolean => {
  const el = document.querySelector<HTMLInputElement>(`input[name="${name}"]`);
  return el?.checked ?? false;
};

export const setupCalculator = (): void => {
  // --- Lecture de la configuration depuis les Custom Attributes Webflow ---
  const formWrapper = document.querySelector<HTMLElement>('.simulator_form-wrapper');
  const rdvRate = parseFloat(formWrapper?.dataset.rdvRate ?? '0.3');
  const privatifRatio = parseFloat(formWrapper?.dataset.privatifRatio ?? '1.5');
  const rdvMonthlyLicence = parseFloat(formWrapper?.dataset.rdvMonthlyLicence ?? '159');
  const privatifMonthlyLicence = parseFloat(formWrapper?.dataset.privatifMonthlyLicence ?? '279');

  // Champ statique : identifie le formulaire pour le routage côté Make (filtre du module Resend).
  // Webflow strippe les `value` statiques sur les inputs au publish, donc on l'injecte ici.
  setHiddenValue('hidden-form-type', 'simulateur');

  // --- Fonction de calcul principale ---
  const calculate = (): void => {
    let caRdv = 0;
    let caPrivatif = 0;
    let caTeamBuilding = 0;
    let licenceMensuelle = 0;

    const flagRdv = isChecked('utilisation-rdv');
    const flagPrivatif = isChecked('utilisation-privatif');
    const flagTeamBuilding = isChecked('utilisation-team-building');

    // Bloc RDV : CA ce soir-là × taux (30%) × 52 semaines
    if (flagRdv) {
      const ca = getInputValue('rdv-ca');
      caRdv = ca * rdvRate * 52;
      licenceMensuelle = Math.max(licenceMensuelle, rdvMonthlyLicence);
    }

    // Bloc Privatif : (Surface ÷ ratio) × Prix joueur × Jours × 52 semaines
    if (flagPrivatif) {
      const surface = getInputValue('input-surface');
      const prix = getInputValue('input-prix-joueur');
      const jours = getInputValue('input-jours');
      const joueurs = privatifRatio > 0 ? surface / privatifRatio : 0;
      caPrivatif = joueurs * prix * jours * 52;
      licenceMensuelle = Math.max(licenceMensuelle, privatifMonthlyLicence);
    }

    // Bloc Team Building : Personnes × Prix joueur × Fréquence × 12 mois
    // Offre événementielle : gratuite (palier 0). Ne fait jamais monter la licence.
    if (flagTeamBuilding) {
      const personnes = getInputValue('input-personnes');
      const prix = getInputValue('input-prix-joueur-team-b');
      const frequence = getInputValue('input-frequence');
      caTeamBuilding = personnes * prix * frequence * 12;
    }

    // Licence = palier le plus élevé parmi les objectifs cochés × 12 (PAS la somme).
    // Un prospect qui coche plusieurs objectifs ne paie qu'une seule licence, la plus chère.
    const licenceCost = licenceMensuelle * 12;

    const caTotal = caRdv + caPrivatif + caTeamBuilding;
    const beneficeNet = caTotal - licenceCost;
    const flagToutCoche = flagRdv && flagPrivatif && flagTeamBuilding;

    // Injection des résultats dans l'écran 4 (affichage formaté)
    setResultText('result-ca-brut', caTotal);
    setResultText('result-cout-licence', licenceCost);
    setResultText('result-benefice-net', beneficeNet);

    // Hidden inputs (payload envoyé à Make → Resend pour le mail prospect).
    // Valeurs en string brute (entier arrondi, pas de séparateur) : le formatting visuel
    // est fait côté template mail.
    const intStr = (n: number) => Math.round(n).toString();
    setHiddenValue('hidden-ca-rdv', intStr(caRdv));
    setHiddenValue('hidden-ca-privatif', intStr(caPrivatif));
    setHiddenValue('hidden-ca-team-building', intStr(caTeamBuilding));
    setHiddenValue('hidden-ca-total', intStr(caTotal));
    setHiddenValue('hidden-cout-licence', intStr(licenceCost));
    setHiddenValue('hidden-gain-net', intStr(beneficeNet));
    // Levier coché → "true" (truthy en IML Make) → le bloc s'affiche.
    // Non coché → "" (string vide, seul falsy fiable pour un input HTML qui ne supporte que des strings).
    // Si on envoyait "false", Make traiterait toute string non vide comme truthy → bug.
    setHiddenValue('hidden-flag-rdv', flagRdv ? 'true' : '');
    setHiddenValue('hidden-flag-privatif', flagPrivatif ? 'true' : '');
    setHiddenValue('hidden-flag-team-building', flagTeamBuilding ? 'true' : '');
    setHiddenValue('hidden-flag-tout-coche', flagToutCoche ? 'true' : '');
  };

  // --- Attache les écouteurs sur tous les champs de l'écran 3 ---
  const inputIds = [
    'rdv-ca',
    'input-surface',
    'input-prix-joueur',
    'input-jours',
    'input-personnes',
    'input-prix-joueur-team-b',
    'input-frequence',
  ];

  inputIds.forEach((id) => {
    const el = document.getElementById(id);
    if (el) el.addEventListener('input', calculate);
  });

  // Recalcule aussi si les checkboxes de l'écran 2 changent
  ['utilisation-rdv', 'utilisation-privatif', 'utilisation-team-building'].forEach((name) => {
    const el = document.querySelector<HTMLInputElement>(`input[name="${name}"]`);
    if (el) el.addEventListener('change', calculate);
  });

  // --- Recalcule à chaque clic sur "Étape suivante" ---
  // Inputflow met un court délai pour animer la transition.
  // On laisse 100ms pour qu'il finisse d'afficher le nouveau step.
  document.querySelectorAll('[if-element="button-next"]').forEach((btn) => {
    btn.addEventListener('click', () => {
      setTimeout(calculate, 100);
    });
  });

  // --- Observer la visibilité du step ROI ---
  // Si Inputflow réinitialise visuellement le step lors de la navigation,
  // on intercepte ce changement et on re-injecte les valeurs calculées.
  const roiStep = document.querySelector('[if-step="ROI"]');
  if (roiStep) {
    const observer = new MutationObserver(() => {
      calculate();
    });
    observer.observe(roiStep, { attributes: true, attributeFilter: ['style', 'class'] });
  }

  // Calcul initial au chargement (pour afficher les valeurs par défaut des sliders)
  calculate();
};
```

export const setupStepValidation = () => {
  const steps = document.querySelectorAll<HTMLElement>('.simulator_step');
  if (steps.length < 2) return;

  const step1 = steps[0];
  const step2 = steps[1];

  const updateButtonState = (button: HTMLElement | null, isValid: boolean) => {
    if (!button) return;
    if (isValid) {
      button.style.opacity = '1';
      button.style.cursor = 'pointer';
    } else {
      button.style.opacity = '0.5';
      button.style.cursor = 'not-allowed';
    }
  };

  // ===============================
  // VALIDATION DE L'ÉTAPE 1 (Radios)
  // ===============================
  const step1Button = step1.querySelector<HTMLElement>('[if-element="button-next"]');

  const getIsStep1Valid = () =>
    !!document.querySelector<HTMLInputElement>('input[name="secteur-activite"]:checked');

  const validateStep1 = () => {
    updateButtonState(step1Button, getIsStep1Valid());
  };

  // Interception musclée du clic AVANT qu'Inputflow ne puisse réagir
  if (step1Button) {
    step1Button.addEventListener('click', (e) => {
      if (!getIsStep1Valid()) {
        e.preventDefault();
        e.stopPropagation(); // Bloque Inputflow
      }
    }, { capture: true });
  }

  validateStep1();
  step1.addEventListener('change', validateStep1);

  // ===================================
  // VALIDATION DE L'ÉTAPE 2 (Checkboxes)
  // ===================================
  const step2Button = step2.querySelector<HTMLElement>('[if-element="button-next"]');

  const getIsStep2Valid = () =>
    !!document.querySelector<HTMLInputElement>(
      'input[name="utilisation-rdv"]:checked, input[name="utilisation-privatif"]:checked, input[name="utilisation-team-building"]:checked'
    );

  const validateStep2 = () => {
    updateButtonState(step2Button, getIsStep2Valid());
  };

  if (step2Button) {
    step2Button.addEventListener('click', (e) => {
      if (!getIsStep2Valid()) {
        e.preventDefault();
        e.stopPropagation(); // Bloque Inputflow
      }
    }, { capture: true });
  }

  validateStep2();
  step2.addEventListener('change', validateStep2);

  // ===================================
  // VALIDATION DU FORMULAIRE FINAL (RGPD)
  // ===================================
  // L'attribut `required` sur la checkbox RGPD doit être retiré côté Webflow :
  // l'input est en `opacity:0`, donc l'erreur de validation HTML5 native s'affiche
  // sous forme de pop-up navigateur peu user-friendly. On valide ici en JS et on
  // applique une classe `is-error` sur le label pour un feedback visible.
  const form = document.getElementById('formulaire-simulateur') as HTMLFormElement | null;
  const rgpdCheckbox = document.getElementById('RGPD') as HTMLInputElement | null;

  if (form && rgpdCheckbox) {
    const rgpdLabel = rgpdCheckbox.closest('.form_checkbox') as HTMLElement | null;

    // Détection défensive : on regarde l'input ET la classe visuelle Webflow
    // (au cas où le couplage label/input se désynchronise).
    const isRgpdChecked = (): boolean => {
      if (rgpdCheckbox.checked) return true;
      const visual = rgpdLabel?.querySelector('.w--redirected-checked');
      return visual !== null && visual !== undefined;
    };

    form.addEventListener('submit', (e) => {
      if (!isRgpdChecked()) {
        e.preventDefault();
        e.stopPropagation();
        if (rgpdLabel) {
          rgpdLabel.classList.add('is-error');
          rgpdLabel.scrollIntoView({ behavior: 'smooth', block: 'center' });
        }
        return;
      }
      // Si le visuel est coché mais l'input pas synchronisée, on force pour
      // que le payload envoie bien la valeur RGPD au backend.
      if (!rgpdCheckbox.checked) rgpdCheckbox.checked = true;
    }, { capture: true });

    rgpdCheckbox.addEventListener('change', () => {
      if (rgpdLabel) rgpdLabel.classList.remove('is-error');
    });
    rgpdLabel?.addEventListener('click', () => {
      // Le label peut être cliqué avant que le change event sur l'input ne fire
      setTimeout(() => {
        if (isRgpdChecked()) rgpdLabel.classList.remove('is-error');
      }, 50);
    });
  }
};

export const setupConditionalDisplay = () => {
  // Inputs de l'étape 2
  const rdvInput = document.querySelector<HTMLInputElement>('input[name="utilisation-rdv"]');
  const privatifInput = document.querySelector<HTMLInputElement>('input[name="utilisation-privatif"]');
  const teamBuildingInput = document.querySelector<HTMLInputElement>('input[name="utilisation-team-building"]');

  // Blocs de l'étape 3
  const rdvBlock = document.querySelector<HTMLElement>('.block-rdv');
  const privatifBlock = document.querySelector<HTMLElement>('.block-privatif');
  const teamBuildingBlock = document.querySelector<HTMLElement>('.block-team-building');

  // Fonction utilitaire pour gérer l'affichage ET les champs requis
  const toggleBlock = (block: HTMLElement | null, isVisible: boolean) => {
    if (!block) return;

    // Gérer l'affichage
    block.style.display = isVisible ? 'block' : 'none';

    // Gérer l'attribut "required" des champs à l'intérieur
    // Si un bloc est caché, ses champs obligatoires empêchent Inputflow de passer à l'étape suivante !
    const inputs = block.querySelectorAll<HTMLInputElement | HTMLSelectElement | HTMLTextAreaElement>('input, select, textarea');
    inputs.forEach(input => {
      if (isVisible) {
        // Restaurer "required" s'il l'était à l'origine
        if (input.dataset.wasRequired === 'true') {
          input.setAttribute('required', '');
        }
      } else {
        // Sauvegarder l'état "required" et le retirer
        if (input.hasAttribute('required')) {
          input.dataset.wasRequired = 'true';
          input.removeAttribute('required');
        }
      }
    });
  };

  // Fonctions de mise à jour pour chaque bloc
  const updateRdvBlock = () => toggleBlock(rdvBlock, rdvInput ? rdvInput.checked : false);
  const updatePrivatifBlock = () => toggleBlock(privatifBlock, privatifInput ? privatifInput.checked : false);
  const updateTeamBuildingBlock = () => toggleBlock(teamBuildingBlock, teamBuildingInput ? teamBuildingInput.checked : false);

  // Initialisation au chargement de la page
  updateRdvBlock();
  updatePrivatifBlock();
  updateTeamBuildingBlock();

  // Écouteurs d'événements "change" sur les checkboxes
  if (rdvInput) rdvInput.addEventListener('change', updateRdvBlock);
  if (privatifInput) privatifInput.addEventListener('change', updatePrivatifBlock);
  if (teamBuildingInput) teamBuildingInput.addEventListener('change', updateTeamBuildingBlock);
};

export const setupProgressBarObserver = () => {
  const steps = document.querySelectorAll<HTMLElement>('.simulator_step');
  const progressItems = document.querySelectorAll<HTMLElement>('.progress_item');

  if (steps.length === 0 || progressItems.length === 0) return;

  const updateProgress = (activeIndex: number) => {
    progressItems.forEach((item, index) => {
      if (index === activeIndex) {
        item.classList.add('is-active');
      } else {
        item.classList.remove('is-active');
      }
    });
  };

  const observer = new MutationObserver((mutations) => {
    mutations.forEach((mutation) => {
      if (
        mutation.type === 'attributes' &&
        (mutation.attributeName === 'style' || mutation.attributeName === 'class')
      ) {
        const target = mutation.target as HTMLElement;
        const index = Array.from(steps).indexOf(target);

        if (index !== -1) {
          // Vérifie si l'étape est devenue visible
          const style = window.getComputedStyle(target);
          if (style.display !== 'none') {
            updateProgress(index);
          }
        }
      }
    });
  });

  steps.forEach((step) => {
    observer.observe(step, { attributes: true, attributeFilter: ['style', 'class'] });
  });

  // Initialisation au chargement de la page
  const activeStepIndex = Array.from(steps).findIndex((step) => {
    return window.getComputedStyle(step).display !== 'none';
  });

  if (activeStepIndex !== -1) {
    updateProgress(activeStepIndex);
  } else {
    updateProgress(0);
  }
};
