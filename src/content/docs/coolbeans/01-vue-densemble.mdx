## En bref

Un seul repo porte deux produits : le **site marketing** `coolbeans.cc`
(vitrine, études de cas, outils) et le **portail client** `my.coolbeans.cc`
(espace connecté : doc, projets, chiffrages, devis). Stack : Astro 7,
Tailwind 4 sur une fondation de tokens Geist, authentification Clerk,
hébergement Cloudflare Workers. Le site vitrine est prérendu (statique) ;
seuls l'espace client et la doc sont rendus serveur, parce que le contrôle
d'accès l'exige.

## Le principe : Coolbeans est le client zéro

Coolbeans figure dans le registre clients du portail comme n'importe quel
client (`src/content/clients/coolbeans.yaml`). Même navigation, mêmes
modules, mêmes règles d'accès. Raison d'être : chaque évolution du portail se
teste d'abord sur soi, dans les conditions réelles d'un client, avant
d'exister pour un vrai client.

Cette doc suit la même logique : c'est la doc « client » de Coolbeans. Elle
combine le manuel d'exploitation (la page Vente) et la doc technique des deux
produits (les pages suivantes). Elle n'est visible que des admins.
