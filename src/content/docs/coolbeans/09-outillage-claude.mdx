L'environnement de travail Claude Code de Ludo : ce qu'il contient et
comment il est sauvegardé pour survivre à la perte d'une machine. Pour tout
réinstaller de zéro sans rien oublier.

## La sauvegarde : le repo dotfiles

Tout ce qui fait l'environnement Claude Code vit dans un repo GitHub privé :
**[github.com/ludobourgoin/dotfiles](https://github.com/ludobourgoin/dotfiles)**.
Si le Mac disparaît, ce repo permet de tout remonter sur une autre machine
en une trentaine de minutes, en suivant son guide `RESTORE.md`.

Ce qu'il contient :

| Dossier      | Contenu                                                                                                                                                                                                                                                                                                           |
| ------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `claude/`    | La configuration Claude Code : réglages (`settings.json`), hooks, commandes personnalisées, barre de statut, les **skills** (catalogue en page suivante), les agents, les **mémoires par projet** (le contexte que Claude accumule), la liste des plugins et la configuration des serveurs MCP (sans les secrets) |
| `dev/`       | Le `CLAUDE.md` global du dossier `/dev` (règles de travail, garde-fous)                                                                                                                                                                                                                                           |
| `shell/`     | Les fichiers de configuration du terminal (`zshrc`, `gitconfig`, statusline)                                                                                                                                                                                                                                      |
| `apps/`      | Les listes de réinstallation : `Brewfile` (Homebrew), applications installées, extensions Chrome et VS Code, packages npm globaux                                                                                                                                                                                 |
| `backup.sh`  | Le script qui régénère tout ce qui précède depuis la machine                                                                                                                                                                                                                                                      |
| `RESTORE.md` | Le guide de restauration pas à pas sur une machine neuve                                                                                                                                                                                                                                                          |

La sauvegarde n'est pas automatique : après tout changement de skill ou de
configuration, relancer `./backup.sh` à la racine du repo, puis commit et
push. Les secrets (tokens, clés SSH, fichiers `.env`) ne sont **jamais**
dans ce repo : ils se récupèrent depuis les dashboards des services ou se
régénèrent, comme détaillé dans `RESTORE.md`.

## Les skills

Un skill est un mode d'emploi que Claude charge à la demande pour une tâche
précise : il se déclenche tout seul quand la demande correspond à sa
description, ou à la main en tapant `/nom-du-skill`. Chaque skill est un
dossier `~/.claude/skills/<nom>/SKILL.md`, sauvegardé dans le repo dotfiles.
S'y ajoutent des plugins tiers installés depuis leurs marketplaces
(superpowers, context-mode, claude-seo, code-review), qui se réinstallent
automatiquement depuis la liste conservée dans dotfiles.

La liste complète, par catégorie, avec l'emplacement de chacun et les mots
qui le déclenchent : [Catalogue des skills](/docs/coolbeans/catalogue-skills).
